## 2024-06-21 - [High] Missing Defense-in-Depth Security Headers in Custom HTTP Daemon
**Vulnerability:** The custom python `BaseHTTPRequestHandler` implementation serving the frontend and API responses completely lacks essential defense-in-depth security headers, leaving users vulnerable to XSS execution, framing attacks (clickjacking), MIME-sniffing, and insecure downgrades.
**Learning:** When building custom HTTP servers (instead of relying on full-featured frameworks like FastAPI/Express that might do this via middleware), developers often focus on core functionality and forget that security headers must be manually injected into every `_write_*` response method.
**Prevention:** Establish a standardized `_send_security_headers()` method that is strictly enforced (or abstracted into a base handler class) to inject `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, `Strict-Transport-Security`, and `X-XSS-Protection` before the response headers are finalized.

## 2024-06-22 - Missing Defense-in-Depth HTTP Headers in BaseHTTPRequestHandler
**Vulnerability:** The HTTP shell (`HttpShellServer` in `control-plane`) was utilizing Python's built-in `http.server.BaseHTTPRequestHandler` but did not inject fundamental security headers (`X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`, `Strict-Transport-Security`, `Content-Security-Policy`). This is because it doesn't automatically attach common security headers like FastAPI or other frameworks would usually do, potentially exposing the application to basic browser vulnerabilities such as XSS and clickjacking.
**Learning:** When using low-level built-in HTTP servers like `BaseHTTPRequestHandler` instead of modern frameworks, security controls like Defense-in-Depth HTTP headers must be manually injected.
**Prevention:** In the future, manually implement and inject `_send_security_headers()` for any HTTP endpoint utilizing raw server implementations or bypass the low-level modules in favor of robust frameworks like FastAPI that manage headers safely by default.

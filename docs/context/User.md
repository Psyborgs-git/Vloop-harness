# User

## Overview
The User is the developer or operator interacting with the VLoop application.

## Responsibilities
- Inputs high-level objectives and tasks via the Tauri UI.
- Configures API keys securely via the local Vault.
- Acts as the Human-in-the-Loop (HITL) to approve or reject actions that exceed token budgets or require network/volume access.
- Views real-time execution logs and audit trails.

## Interactions
- **VLoop Application (Tauri UI)**: The primary interface for all interactions.

# **VLoop v1.4: Complete UI/UX IDE Specification**

**Objective:** Expose 100% of the VLoop backend features through a comprehensive, keyboard-first, CRUD-capable interface without overwhelming the user.

## **1\. Global Shell Architecture**

The app uses a strict 3-pane layout.

* **Pane 1 (Nav \- 5%):** Ultra-slim vertical icon dock.  
* **Pane 2 (Main Workspace \- 60-70%):** Dynamic stage. Houses the Canvas, Tables, and Forms.  
* **Pane 3 (Context/Dev Panel \- 25-35%):** The progressive disclosure pane. Toggles between Human Activity Feed and Raw Proxy/Git logs.

## **2\. Feature Mapping & CRUD Operations**

### **A. The Studio (DAG Canvas & Execution)**

* **Feature:** Time-Travel, Harness Delegation, Mini-App Hosting.  
* **UI:** Infinite pan/zoom canvas.  
* **Interactions:** \* Right-click node \-\> View Diff, View Stderr, Rewind & Fork (triggers Git hard reset).  
  * Bottom command bar for natural language input.  
  * If node type is Serve UI, clicking the node opens a floating internal WebView window rendering the localhost port.

### **B. Adapters & Config (Hexagonal Architecture CRUD)**

* **Feature:** Swap execution sandboxes and databases without code changes.  
* **UI:** Grid of active adapters.  
* **CRUD Ops:**  
  * *Create:* Add new IRelationalDB (e.g., Postgres). Form requires URI, Port, User, Pass.  
  * *Read:* Status indicator (Ping latency to DB/Docker daemon).  
  * *Update/Delete:* Hot-swap the active adapter. Rust microkernel executes graceful systemd restart to apply.

### **C. Harness & Agent Profiles (DSPy Metaprogramming)**

* **Feature:** Manage 3rd party harnesses (Aider/OpenHands) and custom compiled DSPy Signatures.  
* **UI:** Table view of available agents.  
* **CRUD Ops:**  
  * *Create Profile:* Define Harness Type (e.g., Aider), Base Docker Image, Default LLM Model, Max Token Budget, Default Volumes.  
  * *DSPy Signatures:* View/Edit the compiled prompt weights generated by the orchestrator's self-improvement loops.

### **D. Knowledge Base (Continuous RAG)**

* **Feature:** Rust background indexing.  
* **UI:** Dual-pane file manager.  
* **CRUD Ops:**  
  * *Create:* Add local directory path or remote Git repo to watch list.  
  * *Read:* Sync status, chunk count, last indexed timestamp.  
  * *Delete:* Purge specific directories from the active Vector Store.

### **E. Swarm Fleet (P2P Execution)**

* **Feature:** Distributed DAG execution across machines.  
* **UI:** Topology map or detailed data table.  
* **CRUD Ops:**  
  * *Create:* Add remote node IP/Key.  
  * *Read:* Live telemetry (CPU, RAM, Active Sandboxes).  
  * *Update:* Set node rules (e.g., gpu-tasks-only, pause-allocation).

## **3\. The Security Vault**

* Centralized modal for API keys. Handled exclusively by Tauri's native OS credential manager bindings. Keys are never rendered in plain text in the UI after initial entry.
